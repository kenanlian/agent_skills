# Audit persistence

Use this skill as infrastructure for `write-plan`, `execute-plan`, and their review skills. It does not make planning, execution, review, adjudication, or escalation decisions.

## Ownership rule

Separate semantic ownership from file mutation:

- the agent that makes a judgment owns the semantic content;
- this helper owns mechanical serialization and mutation of existing audit files;
- exact copies, timestamps, hashes, Git refs, manifest bookkeeping, and state-file updates must not be regenerated by an LLM when a deterministic operation can produce them;
- immutable raw review reports are written once by the reviewer that produced them and are never rewritten to match later adjudication or fixes.

The helper must never infer a verdict, blocker, decision, deviation, resolution, or verification result. The caller supplies those values.

## Utility

The executable helper is `agents/persist.mjs`. Resolve it from this skill's directory when the host exposes skill paths. If the host cannot execute the helper, use an equivalent deterministic filesystem command or a narrowly scoped file edit; never fall back to reproducing an existing large artifact through model output.

Supported operations:

```text
copy               exact immutable copy; destination must not already exist
write              write a new artifact from stdin or --content-file
set-frontmatter    replace one YAML-frontmatter key
set-field          replace one top-level `Key: value` line
set-list-item      replace one `- Label: value` line inside a named section
append-section     append semantic text to an existing Markdown section
replace-section    replace the body of an existing Markdown section
upsert-table-row   replace or append one Markdown table row keyed by its first cell
```

Examples:

```bash
node <audit-persistence>/agents/persist.mjs copy \
  --source .dev/plan/foo-plan.md \
  --dest .dev/plan-review/foo-review-.../round-01-plan.md

node <audit-persistence>/agents/persist.mjs set-field \
  --file .dev/plan/foo-execution-....md \
  --field Status \
  --value fixing-review-findings

node <audit-persistence>/agents/persist.mjs set-list-item \
  --file .dev/plan/foo-execution-....md \
  --section '## Review gate' \
  --label 'Patch review' \
  --value 'incorrect, round 1, rerun pending'

node <audit-persistence>/agents/persist.mjs upsert-table-row \
  --file .dev/plan/foo-execution-....md \
  --section '## Work packages' \
  --key WP-03 \
  --row '| WP-03 | verified | senior-worker | src/a.ts | V5 pass |'
```

For multi-line semantic text, prefer `--content-file` or stdin rather than shell-escaping a long value.

## Safety

- `copy` and `write --exclusive` fail if the destination exists.
- Never delete, rename, truncate, or overwrite an immutable prior-round artifact.
- `set-frontmatter`, `set-field`, `set-list-item`, `append-section`, `replace-section`, and `upsert-table-row` are for mutable state/index artifacts only, such as execution state and manifests.
- Keep audit paths inside the run directory authorized by the calling skill.
- A helper failure is a persistence failure, not permission to silently omit required audit evidence.
